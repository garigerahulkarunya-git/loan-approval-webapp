About This Project

A full-stack AI web application integrating IBM watsonx.ai for binary loan classification.

Project Overview

Loan Approval Prediction System is an end-to-end machine learning web application that uses an IBM watsonx.ai AutoAI model to predict whether a loan application will be Approved or Rejected based on 11 applicant features.

The model was trained on a real-world loan dataset and deployed as an Online Deployment on IBM Cloud (eu-de region). A Flask backend handles IAM authentication, input validation, and REST API communication — ensuring your credentials are never exposed to the browser.

Python 3.12 Flask 3.0 IBM Cloud IBM AutoAI Bootstrap 5

Dataset Info

  • Source: Loan Approval Prediction CSV
  • Target: Loan_Status (Y / N)
  • Type: Binary Classification
  • Features: 11 input features
  • Platform: IBM watsonx.ai AutoAI
  • Region: eu-de (Frankfurt)
  • Deployment: Online (REST API)

IBM Cloud & watsonx.ai

IBM Cloud is a full-stack cloud platform with over 170 products and services. IBM watsonx.ai is the AI studio within IBM Cloud that provides tools to train, validate, tune, and deploy AI models with full governance.

The deployment endpoint used by this app is hosted in the eu-de (Frankfurt) region:

eu-de.ml.cloud.ibm.com/ml/v4/deployments/…/predictions

Authentication uses IBM IAM (Identity and Access Management) — the Flask backend exchanges your API key for a short-lived Bearer token automatically.

AutoAI Workflow

  1. Data Ingestion — Upload the CSV dataset to IBM watsonx.ai project.
  2. AutoAI Experiment — Configure the target column (Loan_Status) and run.
  3. Pipeline Comparison — AutoAI tries multiple algorithms (Random Forest, XGBoost, etc.) and hyper-parameter combinations.
  4. Best Pipeline — The highest-ranked pipeline is saved as a model.
  5. Online Deployment — Model is deployed as a REST endpoint.
  6. API Call — This Flask app calls the endpoint with a JSON payload and receives prediction + probability.

API Integration Flow

Step 1 — IAM Token

Flask POSTs the IBM_API_KEY to iam.cloud.ibm.com/identity/token to obtain a Bearer token. Token is cached for ~1 hour.

Step 2 — Payload Build

Form data is validated, numeric fields are cast, and Loan_ID is auto-generated. A structured JSON payload is assembled matching the model's expected schema.

Step 3 — Scoring Request

Flask POSTs the payload to the IBM watsonx.ai deployment endpoint with the Bearer token in the Authorization header.

Step 4 — Parse & Display

The response prediction (Y/N) and probability array are parsed. The result is stored in the Flask session and rendered on the result page.
